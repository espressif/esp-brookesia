# ESP-Mosaico 创意工坊蓝图

让第一次接触嵌入式开发的人，在网页上用对话做出自己的小游戏或小工具，并在 Mosaico 上独立运行。

- **创作。** 对话、可操作的方屏预览和安装在同一个作品页。网页和设备桌面围绕新手重新设计。复用 Brookesia 已有的脚本执行、渲染和应用管理能力，以及工坊已验证的结果。
- **作品。** 首版用单个 JavaScript 文件表达界面和行为。网页预览与板端执行使用同一份作品和同一套接口。
- **设备。** 首期适配 Mosaico V1.2，采用 JSON UI / LVGL，暂不适配 GSP。首次由网页引导通过 USB 刷入预编译的 Brookesia 固件，随后继续安装当前作品。日常更新只传作品。设备可以保存多个作品，在桌面打开、退出和切换，拔线后仍可运行。
- **发布。** 先用本机服务和自带模型 API 跑通创作到上板。公开版在账号下保存工程和对话，通过个人主页发布固定版本。其他人打开作品链接即可预览并安装到自己的设备。
